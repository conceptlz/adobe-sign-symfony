    Who makes this SDK, and the open-source work it stands on.

    Conceptualize

    Created and maintained by

    Conceptualize designed and built conceptlz/adobe-sign, conceptlz/adobe-sign-laravel and conceptlz/adobe-sign-symfony, and continues to maintain all three: releases, fixes, testing against real Acrobat Sign accounts, and this documentation. The packages are published on GitHub under the conceptlz organisation and released under the MIT License.

    What maintenance means here

    • Design & developmentThe SDK's architecture: PSR-only core, data-centre routing, retries, ETags, typed exceptions, builders, signature levels and evidence, the Laravel bridge and the Symfony bundle.
    • VerificationEvery request in the test suite is validated against Adobe's published API specification, and behaviour is checked against a real Acrobat Sign account. Differences from the specification are fixed in the SDK and documented.
    • ReleasesAll three packages share one version number and are released together, with a changelog for every version.
    • DocumentationThese sites, the READMEs and the runnable examples, kept in step with the code.
    • SupportBug reports and feature requests through GitHub issues; security reports and other enquiries by email.

    The API specification

    The models and the contract tests are based on the OpenAPI description of the Acrobat Sign REST API v6 that Adobe publishes for developers. Adobe, Acrobat and Acrobat Sign are trademarks of Adobe Inc.; this project is independent of Adobe, as the disclaimer explains.
